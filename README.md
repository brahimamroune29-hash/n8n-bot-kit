# n8n-bot-kit — ابنِ شات بوت وأتمتة داخل n8n مع Claude Code

مهارتان لـ Claude Code. تكتب له بالعربي واش تحتاج، وهو يبني كل شيء **داخل n8n تبعك**: الجداول، وسير العمل، والحرّاس.

| المهارة | تبني |
|---|---|
| `chat-bot` | بوت يرد على زبائنك في **واتساب وإنستغرام وماسنجر**: يجاوب من منتجاتك ومعلوماتك، ياخذ الطلب ويحسب المجموع بنفسه، ما يأكد إلا بعد ما الزبون يشوف الملخص، ما يخترع أسعار، يحوّل لك الزبون وقت اللزوم، يتابع اللي سكت مرتين بلا إزعاج، ويفهم الرسائل الصوتية |
| `automation` | أي أتمتة في n8n بحرّاس تمنع الأعطال الصامتة: منع التكرار، مفتاح إيقاف، سقف يومي، تنبيه عند الخطأ، وتجربة قبل التشغيل |

## 1. اربط n8n بـ Claude Code (مرة وحدة)
1. في n8n: **Settings ← Instance-level MCP ← Enable MCP access**
2. **Connect a client ← Claude Code**، انسخ الأمر اللي يظهر وشغّله في الطرفية.
3. أعد تشغيل Claude Code، واكتب `/mcp`: لازم يظهر `n8n` متصل.

## 2. ركّب الحزمة
داخل Claude Code:

```
/plugin marketplace add brahimamroune29-hash/n8n-bot-kit
/plugin install n8n-bot-kit@n8n-bot-kit
```

ثم أعد تشغيل Claude Code.

## 3. اطلب
افتح مجلد فارغ، شغّل Claude Code، واكتب طلبك. أمثلة:

- «ابنِ لي بوت واتساب لمتجر عطور، الدفع عند الاستلام»
- «ابنِ لي بوت إنستغرام لعيادة يحجز المواعيد»
- «ابنِ لي أتمتة: كي يعبّي زبون الفورم، صنّفه بالذكاء الاصطناعي وابعث لي تنبيه إذا كان جاد»

أو نادِ المهارة مباشرة: `/n8n-bot-kit:chat-bot` أو `/n8n-bot-kit:automation`.

Claude يسألك أسئلة قليلة، يطلب منك تضيف المفاتيح في n8n بيدك (ما تكتبها في المحادثة أبداً)، يبني ويتحقق، وما يشغّل شيء قبل موافقتك.

## واش تحتاج
- n8n نسخة 2.35 أو أحدث (n8n السحابي يكفي)
- مفتاح [OpenRouter](https://openrouter.ai) للردود
- لواتساب: حساب [Wasender](https://wasenderapi.com)
- لإنستغرام وماسنجر: صفحة فيسبوك مربوطة بحساب إنستغرام احترافي
- اختياري: مفتاح OpenAI لتفريغ الرسائل الصوتية

## قواعد الأمان
- المفاتيح في **Credentials** داخل n8n فقط.
- البوت يبدأ في وضع التجربة: يرد فقط على الأرقام في `test_numbers`. لما ترضى عليه، فرّغ الخانة ويشتغل للكل.
- بوت واحد فقط على كل رقم: إذا عندك بوت قديم، طفّيه في نفس الدقيقة.
- تقدر توقف البوت كامل في أي لحظة: جدول `bot_settings` ← `bot_enabled` = `false`.
